# 光影集 · 智能摄影云社区平台

> 面向**校园摄影社团 / 小型摄影团队 / 个人摄影师**的摄影资产管理 + 创作社区平台。
> 既保存原图资产（空间、配额、AI 编目），也支持把作品发布到社区（互动、审核、策展），并用一颗「光影星图」把全部作品连成宇宙。

**技术栈**：Vue 3.5 + Ant Design Vue 4.2 + Pinia + Three.js + ECharts ｜ Spring Boot **3.5.8**（Java **17**）+ MyBatis-Plus 3.5.9 + Sa-Token + Spring Session + MySQL + Redis + 腾讯云 COS + 数据万象 CI + Spring AI Alibaba 1.1.2

## 🧠 AI 能力

AI 是这个平台的一等公民，覆盖「资产进站 → 理解归档 → 找回 → 选片 → 对话」全链路：

| 能力 | 说明 |
| --- | --- |
| **AI 摄影编目** | 上传即自动提取 EXIF（自研零依赖 JPEG/TIFF 解析器，兼容 IFD0 / Exif 子 IFD，输出相机/镜头/光圈/快门/ISO 等）+ 智能打标（主体 / 场景 / 光线 / 构图四类标签）落库资产元数据 |
| **权限感知语义检索** | 用一句话搜自己的图（"城市夜景"、"横构图"），**只返回你有权访问的图片**，并给出命中依据：命中字段、命中标签、匹配分值、权限理由 |
| **检索命中依据可视化** | 前端把 AI 的判断过程画出来：置信条（分值归一化）、按字段类型着色的命中徽章、可点击的命中标签二次检索 |
| **相似分组辅助选片** | 并查集 + 拍摄时间窗 + 尺寸 + 主色 + 标签重合度 + 相机型号多维聚类，输出"推荐保留候选"与分组理由，连拍选片不再翻到手软 |
| **AI 任务状态机** | 编目任务 QUEUED → RUNNING → SUCCEEDED / FAILED → RETRYING（上限 3 次）→ CANCELLED，可取消、可查看我的任务列表 |
| **AI 拍摄助手对话** | 意图路由 + 工具调用层（检索 / 统计 / 元数据）+ 流式回答 + 会话持久化；未配置大模型密钥时自动降级为本地模板回答，功能不缺席 |
| **数据万象 CI** | 上传即压缩 webp + 缩略图 + 主色提取（PicOperations），原图资产与展示图分离 |

## 🚀 快速开始

```powershell
# 0. 前置：JDK 17、Node 18+、MySQL 3306、Redis 6379（Redis 未启动会导致所有登录 500）
# 1. 数据库：依次执行 picture-backend/sql/migration/ 下的迁移脚本（幂等，可重复执行）
# 2. 后端（默认 8123）——注意 WorkBuddy 等宿主环境可能注入 SERVER__PORT 覆盖端口，显式指定：
cd picture-backend
$env:SERVER__PORT="8123"; $env:SERVER_PORT="8123"
mvn spring-boot:run
# 3. 前端（默认 5173）
cd picture-frontend
npm install
npm run dev
```

- 接口文档（springdoc）：http://localhost:8123/api/swagger-ui/index.html
- COS 密钥放在 `picture-backend/src/main/resources/application-local-dev.yml`（已 gitignore）
- 完整环境排查见 **智能摄影云社区平台-从零启动指南.md**
