# 光影集 · 智能摄影云社区平台

> 面向**校园摄影社团 / 小型摄影团队 / 个人摄影师**的摄影资产管理 + 创作社区平台。
> 既保存原图资产（空间、配额、AI 编目），也支持把作品发布到社区（互动、审核、策展）。

**技术栈**：Vue 3.5 + Ant Design Vue 4.2 + Pinia + ECharts ｜ Spring Boot **3.5.8**（Java **17**）+ MyBatis-Plus 3.5.9 + Sa-Token + Spring Session + MySQL + Redis + 腾讯云 COS + Spring AI Alibaba 1.1.2

---

## 快速开始

```powershell
# 1. 依赖：MySQL 3306、Redis 6379 必须启动（Redis 未启动会导致所有登录 500）
# 2. 数据库：依次执行 picture-backend/sql/migration/ 下的迁移脚本（幂等，可重复执行）
# 3. 后端（默认 8123）
cd picture-backend; mvn spring-boot:run
# 4. 前端（默认 5173）
cd picture-frontend; npm install; npm run dev
```

- 接口文档（springdoc）：http://localhost:8123/api/swagger-ui/index.html
- 数据库变更与迁移说明见 **数据库变更记录.md**；每轮开发做了什么见 **开发日志.md**

## 智能摄影云社区增量说明

本工作区在原云图库能力之上增加了摄影社区领域层，原有图片上传、空间、审核、COS 和协同编辑功能保持兼容。新增演示入口包括 `/community`、`/ai-workbench` 和 `/access-center`。

首次运行时，推荐执行 `picture-backend/sql/init_smart_photo_community.sql` 一次性初始化数据库；也可以按顺序执行 `picture-backend/sql/create_table.sql` 和 `picture-backend/sql/photo_community.sql`。AI 工作台默认使用本地可运行的 `LOCAL_FALLBACK` 编目器，阿里云扩图密钥为可选配置；访问控制使用每日下载配额和团队邀请码，不包含积分、充值或内容付费。
